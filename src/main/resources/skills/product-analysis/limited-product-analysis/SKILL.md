# Name

limited-product-analysis

# Description

面向单个或少量保险产品的受限产品分析 Skill。当前阶段仅定义能力边界，用于后续 ProductAnalysisAgent 加载产品分析策略、输入约束和输出结构。

# When To Use

当用户需要对一个保险产品，或少量候选保险产品进行条款、保障责任、费用、适用客群、风险提示等维度的结构化分析时使用。

# Available Tools

当前可用业务工具：

- product_analysis：根据产品编码、客户画像和分析维度查询Mock产品库，并返回结构化产品分析结果。

# Input

- 产品名称或产品编码
- 客户需求描述
- 可选的对比维度
- 可选的风险偏好和预算信息

# Output

必须使用以下 Markdown 小标题输出：

## 分析结论

- 用 2 到 4 句话给出结论。
- 必须说明该结论是基于已查询到的产品信息和用户输入作出的阶段性分析。

## 产品事实

- 产品名称
- 产品类型
- 核心保障责任
- 缴费或期限信息
- 明确来自工具返回结果的信息

## 适配分析

- 客户需求匹配点
- 不匹配或信息不足的地方
- 仅可基于工具返回和用户输入做有限推断

## 风险提示

- 免责、等待期、退保损失、费用或收益不确定性等风险
- 若工具结果没有提供对应信息，必须明确说明“当前信息不足，需人工复核”

## 后续建议

- 建议补充的信息
- 需要人工顾问、核保、法务或合规复核的事项

# Rules

- 只要用户请求涉及具体产品编码、产品名称或产品对比，必须优先调用可用的产品分析工具。
- 不得把产品分析工具返回之外的信息包装成产品事实。
- 不承诺收益。
- 不替代人工投顾、核保、法务或合规审查。
- 输出必须区分事实、推断和建议。
- 对缺失信息必须明确标注，不得编造产品条款。
- 金融合规风险优先于表达流畅性。

# Examples

输入：分析某终身寿险产品是否适合高净值客户做长期资产配置。

输出：按照分析结论、产品事实、适配分析、风险提示和后续建议给出结构化分析。
