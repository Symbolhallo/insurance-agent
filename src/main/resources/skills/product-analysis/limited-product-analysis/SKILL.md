# Name

limited-product-analysis

# Description

面向单个或少量保险产品的受限产品分析 Skill。当前阶段仅定义能力边界，用于后续 ProductAnalysisAgent 加载产品分析策略、输入约束和输出结构。

# When To Use

当用户需要对一个保险产品，或少量候选保险产品进行条款、保障责任、费用、适用客群、风险提示等维度的结构化分析时使用。

# Available Tools

当前 Phase1 不启用 Tool Calling。

后续可接入的工具类型包括：

- 产品基础信息查询 Tool
- 产品条款解析 Tool
- 费率与利益演示 Tool
- 合规风险校验 Tool

# Input

- 产品名称或产品编码
- 客户需求描述
- 可选的对比维度
- 可选的风险偏好和预算信息

# Output

- 产品摘要
- 核心保障责任
- 适用客群
- 主要优势
- 主要限制
- 风险提示
- 结论建议

# Rules

- 不承诺收益。
- 不替代人工投顾、核保、法务或合规审查。
- 输出必须区分事实、推断和建议。
- 对缺失信息必须明确标注，不得编造产品条款。
- 金融合规风险优先于表达流畅性。

# Examples

输入：分析某终身寿险产品是否适合高净值客户做长期资产配置。

输出：按照产品摘要、保障责任、现金价值特点、适用客群、限制条件、风险提示和结论建议给出结构化分析。
