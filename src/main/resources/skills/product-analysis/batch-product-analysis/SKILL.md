# Name

batch-product-analysis

# Description

面向多款保险产品的批量对比分析 Skill。当前阶段仅定义能力描述，用于后续支持产品对比矩阵、优先级排序和推荐理由生成。

# When To Use

当用户需要同时比较多款保险产品，或希望从多个候选产品中筛选适合特定客户需求的产品组合时使用。

# Available Tools

当前 Phase1 不启用 Tool Calling。

后续可接入的工具类型包括：

- 批量产品信息查询 Tool
- 产品责任对比 Tool
- 保费测算 Tool
- 客群匹配 Tool
- 合规限制检查 Tool

# Input

- 产品列表
- 客户画像
- 分析目标
- 对比维度
- 可选的预算、期限、风险偏好和保障偏好

# Output

- 产品对比矩阵
- 各产品优势与限制
- 客户需求匹配度
- 排序结果
- 推荐理由
- 风险提示

# Rules

- 不输出未经依据支持的排名。
- 不夸大产品收益或保障范围。
- 不隐藏免责、等待期、缴费期限、退保损失等关键限制。
- 若产品信息不足，必须要求补充信息或标注无法判断。
- 所有建议必须保留人工复核空间。

# Examples

输入：比较三款重疾险产品，目标客户为35岁家庭经济支柱，关注保费、保障范围和赔付条件。

输出：生成产品对比矩阵，列出保障责任、保费差异、赔付条件、适用性排序和风险提示。
