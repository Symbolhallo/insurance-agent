# Name

batch-product-analysis

# Description

面向多款保险产品的批量对比分析 Skill。当前阶段仅定义能力描述，用于后续支持产品对比矩阵、优先级排序和推荐理由生成。

# When To Use

当用户需要同时比较多款保险产品，或希望从多个候选产品中筛选适合特定客户需求的产品组合时使用。

# Available Tools

当前可用业务工具：

- product_analysis：根据多个产品编码、客户画像和分析维度查询Mock产品库，并返回结构化产品分析结果。

# Input

- 产品列表
- 客户画像
- 分析目标
- 对比维度
- 可选的预算、期限、风险偏好和保障偏好

# Output

必须使用以下 Markdown 小标题输出：

## 对比结论

- 用 2 到 4 句话说明整体对比结果。
- 若工具结果缺少部分产品，必须先说明缺失产品编码。

## 产品对比表

| 产品 | 类型 | 核心保障/权益 | 适配点 | 主要限制 | 信息完整度 |
| --- | --- | --- | --- | --- | --- |

## 适配排序

- 只能基于工具返回结果和用户画像排序。
- 每个排序理由必须说明依据。
- 若依据不足，不得强行排序。

## 关键风险

- 必须列出各产品可能存在的主要风险。
- 对免责、等待期、退保损失、收益不确定性等缺失信息，必须标注“当前信息不足，需人工复核”。

## 后续建议

- 建议补充的信息
- 建议人工顾问、核保、法务或合规复核的事项

# Rules

- 只要用户请求涉及具体产品编码、产品名称或产品对比，必须优先调用可用的产品分析工具。
- 不得把产品分析工具返回之外的信息包装成产品事实。
- 不输出未经依据支持的排名。
- 不夸大产品收益或保障范围。
- 不隐藏免责、等待期、缴费期限、退保损失等关键限制。
- 若产品信息不足，必须要求补充信息或标注无法判断。
- 所有建议必须保留人工复核空间。

# Examples

输入：比较三款重疾险产品，目标客户为35岁家庭经济支柱，关注保费、保障范围和赔付条件。

输出：按照对比结论、产品对比表、适配排序、关键风险和后续建议给出结构化分析。
