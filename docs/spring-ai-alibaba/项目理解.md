# 各类ID
| 编号                   | 表示什么                   |
| -------------------- | ---------------------- |
| `conversationId`     | 一整段对话                  |
| `requestId`          | 前端的一次幂等请求              |
| `workflowInstanceId` | 后端创建的一次工作流执行           |
| `threadId`           | Graph Checkpoint 的执行线程 |
| `traceId`            | 日志排查链路                 |
| `taskId`             | Planner 产生的某一个子任务      |
| `invocationId`       | 某一次 Agent 调用审计编号       |
